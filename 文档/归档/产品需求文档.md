# Roguelike 回合制策略游戏 - 产品需求文档

---

## 一、需求拆解

### 核心定位
Roguelike + 回合制策略 + 程序化生成 + AI行为树

### 功能需求分解

#### 1. 程序化关卡生成系统（核心）
| 子模块 | 功能描述 | 优先级 |
|--------|---------|-------|
| 地图生成算法 | 基于分层或房间连接的随机地图生成（如BSP、随机漫步、Cell Automata） | P0 |
| 多楼层/关卡 | 多层级关卡递进，每层难度递增 | P0 |
| 房间类型 | 战斗房、商店房、宝箱房、精英房、Boss房、事件房、休息房 | P0 |
| 地图可视化 | 俯视角网格地图，可探索迷雾/战争迷雾 | P0 |
| 关卡主题 | 不同楼层拥有不同的视觉主题（如地下城、森林、火山、冰原） | P1 |
| 隐藏房间 | 特殊条件触发的隐藏房间 | P1 |

#### 2. 战斗系统（核心）
| 子模块 | 功能描述 | 优先级 |
|--------|---------|-------|
| 回合制战斗 | 玩家与敌人轮流行动，行动包括移动、攻击、使用道具、技能 | P0 |
| 行动点系统 | 每回合有限行动点（AP），不同行动消耗不同AP | P0 |
| 移动机制 | 网格或自由移动，受地形影响 | P0 |
| 攻击方式 | 近战、远程、范围攻击、特殊技能 | P0 |
| 伤害计算 | 基于攻击力、防御力、暴击率、元素克制等公式 | P0 |
| 状态效果 | 中毒、燃烧、冰冻、眩晕、减速、护盾等 | P1 |
| 连击/组合技 | 特定技能顺序或条件触发组合效果 | P1 |
| 环境互动 | 可破坏障碍物、陷阱、地形效果 | P1 |

#### 3. AI敌人行为树
| 子模块 | 功能描述 | 优先级 |
|--------|---------|-------|
| 行为树架构 | 选择节点、顺序节点、条件节点、动作节点 | P0 |
| 基础AI | 巡逻→追击→攻击→撤退的基础行为循环 | P0 |
| 精英AI | 特殊技能释放逻辑、召唤小怪、狂暴模式 | P0 |
| Boss AI | 多阶段行为树、全屏技能、召唤物、状态切换 | P0 |
| 协同AI | 多个敌人之间的战术配合 | P1 |
| 适应性AI | 根据玩家行为调整策略（如防风筝、防绕后） | P1 |
| 行为可视化 | 编辑器模式下可查看AI决策过程 | P2 |

#### 4. 物品与装备系统（组合制策略）
| 子模块 | 功能描述 | 优先级 |
|--------|---------|-------|
| 物品随机化 | 物品属性、稀有度、词缀随机生成 | P0 |
| 装备系统 | 武器、防具、饰品，可穿戴和替换 | P0 |
| 道具系统 | 消耗品（回血、增益、临时buff） | P0 |
| 遗物/神器 | 永久性被动加成，不可移除 | P0 |
| 物品合成 | 组合多个物品合成高级物品 | P1 |
| 套装效果 | 穿戴特定组合装备触发额外效果 | P1 |
| 物品鉴定 | 未鉴定物品需在特定地点或使用道具鉴定 | P2 |

#### 5. 角色与成长系统
| 子模块 | 功能描述 | 优先级 |
|--------|---------|-------|
| 角色选择 | 多个角色可选，每个角色有独特技能和属性 | P0 |
| 等级系统 | 战斗经验 → 升级 → 属性提升 | P0 |
| 技能树 | 每次升级可选择技能/天赋加点 | P0 |
| 局外成长 | 全局解锁系统（新角色、新物品、新难度） | P1 |
| 符文/铭文 | 战斗前配置的被动加成系统 | P1 |

#### 6. 永久死亡与局外循环
| 子模块 | 功能描述 | 优先级 |
|--------|---------|-------|
| 永久死亡 | 角色死亡后本次局内进度清零 | P0 |
| 全局货币 | 每局获得的货币用于局外解锁 | P0 |
| 解锁系统 | 用全局货币解锁新角色、物品、天赋 | P0 |
| 难度解锁 | 通关后解锁更高难度 | P1 |
| 成就系统 | 特定条件达成解锁成就和奖励 | P1 |

#### 7. 游戏流程
| 子模块 | 功能描述 | 优先级 |
|--------|---------|-------|
| 开局准备 | 选择角色、配置初始装备/天赋 | P0 |
| 关卡探索 | 在地图上选择前进路线 | P0 |
| 楼层Boss | 每层最终挑战Boss | P0 |
| 最终Boss | 通关最终Boss即为胜利 | P0 |
| 结算界面 | 展示本局数据统计、获得奖励 | P0 |

#### 8. UI/UX
| 子模块 | 功能描述 | 优先级 |
|--------|---------|-------|
| HUD | 血量、行动点、物品栏、小地图 | P0 |
| 背包界面 | 查看和管理物品 | P0 |
| 角色状态面板 | 详细属性、技能、状态效果 | P0 |
| 设置菜单 | 音量、画面、键位设置 | P0 |
| 教程系统 | 新手引导和提示 | P1 |
| 日志/图鉴 | 已解锁物品、敌人、成就的图鉴 | P1 |

#### 9. 技术需求
| 子模块 | 功能描述 | 优先级 |
|--------|---------|-------|
| 存档系统 | 局内自动存档和读档 | P0 |
| 性能优化 | 程序化生成和AI计算的性能保障 | P0 |
| 随机种子 | 支持种子输入，可复现同一局 | P1 |

## 二、用户画像

### 核心用户画像

#### 画像A：硬核策略玩家
| 属性 | 描述 |
|------|------|
| 年龄 | 22-35岁 |
| 职业 | 大学生、程序员、工程师 |
| 游戏经验 | 10年+游戏经验，重度游戏玩家 |
| 偏好类型 | 策略游戏、Roguelike、RPG |
| 游戏时长 | 每周15-25小时 |
| 核心诉求 | 深度策略性、高难度挑战、Build多样性 |
| 痛点 | 市面上大多数游戏缺乏真正的策略深度，通关后缺乏重复可玩性 |
| 典型场景 | 下班后花30分钟-1小时打一局，追求每一次决策都有意义 |
| 代表游戏 | 杀戮尖塔、暗黑地牢、Into the Breach、FTL |

#### 画像B：Roguelike爱好者
| 属性 | 描述 |
|------|------|
| 年龄 | 18-30岁 |
| 职业 | 学生、游戏主播、内容创作者 |
| 游戏经验 | 5年+，熟悉Roguelike品类 |
| 偏好类型 | Roguelike、Roguelite、独立游戏 |
| 游戏时长 | 每周10-20小时 |
| 核心诉求 | 新鲜感、随机性带来的惊喜、收藏和解锁要素 |
| 痛点 | 很多Roguelike游戏随机性太强，策略性不足，运气>技术 |

| 代表游戏 | 以撒的结合、挺进地牢、死亡细胞、哈迪斯 |

| 属性 | 描述 |
|------|------|

| 职业 | 白领、管理者、自由职业 |

#### 竞品设计风格
- 视觉风格：手绘风格，2D平面，色彩鲜明，界面简洁
- 美术风格：偏卡通化，角色和怪物设计独特
- UI设计：信息层级清晰，操作反馈即时
- 音乐音效：氛围感强的BGM，战斗音效节奏感强
- 整体调性：硬核但不严肃，带有幽默感

#### SWOT分析

| 维度 | 分析 |
|------|------|
| **优势（Strengths）** | 1. 回合制策略天然适合PC/移动端，反应门槛低<br>2. 程序化地图 + 网格移动比卡牌路线选择更具空间策略感<br>3. 网格战棋 + 环境互动，策略深度更高<br>4. AI行为树比固定卡牌模式更动态<br>5. 物品组合制（装备+遗物+技能）比纯卡牌Build更丰富 |
| **劣势（Weaknesses）** | 1. 杀戮尖塔有先发优势和庞大用户基础<br>2. 网格战棋节奏比卡牌慢，移动端适配难度大<br>3. 开发复杂度远高于卡牌游戏<br>4. 缺乏成熟的品类认知（杀戮尖塔=卡牌Roguelike的标杆）<br>5. 美术和音乐资产需要大量投入 |
| **机会（Opportunities）** | 1. Roguelike+战棋品类尚未出现头部产品，市场空白大<br>2. 回合制策略游戏在移动端和PC端均有稳定受众<br>3. 独立游戏市场持续增长，Steam和移动平台分发渠道成熟<br>4. 可以加入杀戮尖塔没有的"空间战术"维度<br>5. 中文+全球化同时发行，收割两类市场 |
| **威胁（Threats）** | 1. 大厂可能入局Roguelike战棋赛道<br>2. 同类竞品（如《暗黑地牢2》《漫威暗夜之子》）已有一定市场<br>3. 程序化生成和AI行为树开发难度大，Bug风险高<br>4. 回合制策略游戏受众相对小众<br>5. 如果平衡性做不好，随机性会导致负面体验 |

#### 差异化策略建议
| 维度 | 差异化方向 |
|------|-----------|
| 核心玩法 | 卡牌→**网格战棋**，增加空间位置策略维度 |
| 交互方式 | 纯卡牌操作→**地图上移动+攻击+技能**的立体操作 |
| AI系统 | 固定行为模式→**行为树驱动**，敌人更智能 |
| 环境互动 | 无→**可破坏地形、陷阱、元素反应** |
| Build多样性 | 卡牌组合→**装备+遗物+技能+地形**多维组合 |
| 战斗节奏 | 快速卡牌对攻→**可深思熟虑的回合制战棋** |

### 开发阶段规划

#### 第一阶段：核心原型（MVP）
**目标：可玩的核心循环**
- 程序化地图生成（基础房间+走廊）
- 1个角色（基础属性和技能）
- 基础战斗系统（移动+攻击，网格回合制）
- 2-3种基础敌人（简单AI行为树）
- 基础物品系统（武器+药水）
- 1层关卡 + 1个Boss
- 永久死亡 + 结算
- 基础HUD

#### 第二阶段：内容填充
**目标：丰富游戏内容**
- 3-4个完整角色（每个独特技能树）
- 5层关卡 + 多种房间类型
- 精英敌人 + Boss AI多阶段
- 完整物品系统（装备+遗物+消耗品）
- 局外成长（货币+解锁）
