# 《迷城棋局 Labyrinth Chess》游戏策划案

> 本策划案依据当前代码实现（`d:\code\roguelike\src`）整理，与游戏实际玩法一致。
> 更新时间：2026-08-30

---

## 一、游戏概述

- **类型**：像素风回合制战棋肉鸽（Roguelike）
- **技术栈**：Python 3.13 + pygame-ce 2.5.7，PyInstaller 打包 exe
- **核心卖点**：元素反应连招、AP 行动点策略、多阶段敌人、永久死亡
- **单局目标**：3 层地牢，每层击败 Boss 下楼梯，通关后开启新周目

## 二、核心循环

```
探索房间 → 触发战斗 → 击杀掉落金币 → 商店买装备 / 休息房学技能或天赋
→ 击败 Boss → 下楼梯进入更深层 → 死亡即删档，一切重开
```

## 三、数值设计

### 3.1 玩家基础属性（Lv1）

| 属性 | 值 | 说明 |
|------|-----|------|
| 生命 HP | 20 | 永久死亡，无回复手段必须靠药水/休息 |
| 攻击 ATK | 6 | 受武器 / 力量药水加成 |
| 防御 DEF | 2 | 减伤公式见下 |
| 行动点 AP | 5 | 移动 / 技能都消耗 AP |
| 移动范围 | 3 格 | 每回合移动花 1 AP |
| 暴击率 | 10% | 暴击伤害 ×1.5 |
| 初始技能 | 基础攻击 | 其余技能在休息房学 |
| 初始金币 | 30 | 商店消费 |

### 3.2 伤害公式

```
基础伤害 = max(1, int(ATK × 倍率 − DEF × 0.5))
暴击伤害 = 基础 × 1.5（暴击率 10%）
破甲状态：DEF × 0.5
元素弱点/抗性：×1.25 / ×0.75
最终扣血 = 伤害 × 反应倍率 + 反应追加 → 感电受击 ×1.5 / 融化受击 ×1.25 → 护盾吸收
```

### 3.4 元素反应（战斗核心）

附着规则：命中非物理技能给目标附元素（持续 2 回合），同元素刷新；异元素命中构成反应则触发并消耗附着。

| 反应 | 组合 | 效果 |
|------|------|------|
| 蒸发 | 火 + 水 | 本次伤害 ×1.5 |
| 冻结 | 冰 + 水 | 目标跳过下一回合 |
| 感电 | 雷 + 水 | 追加 (2+ATK) 伤害 + 受击 ×1.5，2 回合 |
| 超导 | 雷 + 冰 | 追加 (1+ATK) 伤害 + 破甲（DEF-50%），2 回合 |
| 融化 | 火 + 冰 | 追加 (1+ATK) 伤害 + 受击 ×1.25 |
| 超载 | 雷 + 火 | 追加 (1+ATK) 伤害 + 延迟爆炸 |

### 3.7 经济

- 背包：B 键打开，装备/喝药，右上角关闭

## 四、地图与房间

- 地图 40×40 瓦片，**等分网格布局**：2 列 × 3 行，共 6 个固定尺寸房间
- 每房固定 10×8，直线走廊直连 + 环路，保证全图连通
- 房间类型：**1 Boss + 1 精英 + 1 商店 + 1 休息 + 2 战斗**（出生在休息房）
- 战斗/精英/Boss 房随机放置 6~10 根障碍柱（挡路 + 挡远程视线）
- 战争迷雾：未探索全黑、已探索半透明遮罩；视线用 Bresenham 直线检测

## 五、战斗系统

- **回合制战棋**：玩家回合 → 手动空格结束 → 敌人回合，按顺序结算
- **AP 行动点**：移动花 1 AP（可走 3 格）、技能按表消耗
- **AP 耗尽不自动结束回合**，需手动结束（提示"AP已耗尽"）
- 鼠标点击移动（蓝色高亮范围）/ 点击敌人攻击（红色）
- 1~6 切换技能、M 移动模式、H 喝药、空格结束回合
- 火球 3×3 溅射 / 雷击直线穿透，远程技能受障碍柱视线阻挡
- **锁房机制**：进入战斗/精英/Boss 房自动开战后，房间上锁，全灭敌人才能离开（无法逃战）

## 六、敌人设计

| 敌人 | HP/ATK/DEF | 行为 |
|------|-----------|------|
| 史莱姆 | 8 / 3 / 1 | 近战贴脸，移动 2 |
| 骷髅 | 12 / 4 / 1 | 远程风筝，保持距离射击 |
| 精英 | 20 / 5 / 2 | 阶段1 远程消耗 → 血量70%召唤史莱姆 → 血量40%狂暴连击 |
| Boss | 80 / 8 / 3 | 阶段1 普攻 → 阶段2 连击 → 血量40%全屏震击（AOE 半径3，覆盖 7×7，附带粒子特效） |

- **楼层缩放**：每层敌人 HP/ATK ×1.2（L3 即 ×1.4）
- **L2 起战斗房 3 敌人**（1 史莱姆 + 2 骷髅），提高远程压力
- 敌人受击后同回合不再移动；行走动画静止 0.7 秒回待机

## 八、存档与死亡

- **存档**：JSON 单槽，存 `saves/`（打包版存 exe 旁）；只存基础攻击力（防武器加成翻倍 bug）
- **永久死亡**：死亡后等敌人攻击动画播完再跳结算 → 删档 → 回主菜单重开
- 暂停菜单：继续 / 保存 / 退出

## 九、数值平衡现状（2026-08-30 模拟器结论）

> 模拟器 `tests/balance_sim.py`：真实地形 + AI + 伤害公式，每场景 200 场无头蒙特卡洛。

| 楼层 | 战斗房×2 | 精英房 | Boss | 全层资源 vs 承受 |
|------|---------|--------|------|----------------|
| L1（基础+冲锋斩，1药水）| 96% / 3.8HP | **31%** / 24.4HP | **0%** / 24.1HP | 45 vs 56 缺口 |
| L2（+火球，2药水）| 100% / 10.2HP | 100% / 3.5HP | 66% / 24.6HP | 60 vs 49 宽裕 |
| L3（+AP，2药水）| 100% / 14.8HP | 100% / 6.8HP | **23%** / 43.4HP | 60 vs 80 缺口 |

**结论与决策**：
- L1 难（精英 31%、Boss 0%，近战被远程风筝）→ **保持**，靠药水/操作过关
- L2 火球质变 → **已加强** L2 战斗房敌人（2→3）
- L3 Boss 超模（缩放 ×1.4）→ **保持**，玩家体感爽局依赖装备
- 遗留观察：L1 Boss 对近战无解；治疗药水 15HP 相对后期伤害偏弱
