---

## 一、用户画像

### 核心用户画像

#### 画像A：硬核策略玩家
| 属性 | 描述 |
|------|------|
| 年龄 | 22-35岁 |
| 职业 | 大学生、程序员、工程师 |
| 游戏经验 | 10年+游戏经验，重度游戏玩家 |
| 偏好类型 | 策略游戏、Roguelike、RPG |
| 游戏时长 | 每周15-25小时 |
| 核心诉求 | 深度策略性、高难度挑战、Build多样性 |
| 痛点 | 市面上大多数游戏缺乏真正的策略深度，通关后缺乏重复可玩性 |
| 典型场景 | 下班后花30分钟-1小时打一局，追求每一次决策都有意义 |
| 代表游戏 | 杀戮尖塔、暗黑地牢、Into the Breach、FTL |

#### 画像B：Roguelike爱好者
| 属性 | 描述 |
|------|------|
| 年龄 | 18-30岁 |
| 职业 | 学生、游戏主播、内容创作者 |
| 游戏经验 | 5年+，熟悉Roguelike品类 |
| 偏好类型 | Roguelike、Roguelite、独立游戏 |
| 游戏时长 | 每周10-20小时 |
| 核心诉求 | 新鲜感、随机性带来的惊喜、收藏和解锁要素 |
| 痛点 | 很多Roguelike游戏随机性太强，策略性不足，运气>技术 |
| 典型场景 | 直播或录制视频，追求有趣的组合和戏剧性场面 |
| 代表游戏 | 以撒的结合、挺进地牢、死亡细胞、哈迪斯 |

#### 画像C：休闲策略玩家
| 属性 | 描述 |
|------|------|
| 年龄 | 25-40岁 |
| 职业 | 白领、管理者、自由职业 |
| 游戏经验 | 5年+，但时间有限 |
| 偏好类型 | 回合制策略、战棋、卡牌 |
| 游戏时长 | 每周5-10小时 |
| 核心诉求 | 碎片化时间可玩、节奏可控、有成就感 |

| 典型场景 | 通勤地铁上、午休时间、睡前打一局 |
| 代表游戏 | 文明系列、火焰纹章、XCOM |

## 二、竞品分析

### 竞品选择：杀戮尖塔（Slay the Spire）

#### 竞品基本信息
| 项目 | 内容 |
|------|------|
| 名称 | Slay the Spire（杀戮尖塔） |
| 开发商 | Mega Crit Games |
| 发行时间 | 2019年（正式版） |
| 游戏类型 | Roguelike卡牌策略 |
| 售价 | $24.99 |
| 平台 | Steam、Switch、iOS、Android |
| 销量 | 500万+ |

#### 竞品功能列表

| 功能模块 | 杀戮尖塔实现 | 备注 |
|---------|-------------|------|
| 角色系统 | 4个角色，每个有独特卡池和机制 | 角色差异化明显 |
| 卡牌系统 | 攻/防/技能/能力四类卡牌 | 回合制卡牌核心 |
| 遗物系统 | 200+遗物，提供被动效果 | 组合Build的关键 |
| 药水系统 | 消耗品，临时效果 | 辅助性道具 |
| 地图系统 | 分层节点式路线选择 | 每层3-4条路线 |
| 战斗系统 | 回合制卡牌对战 | 每回合抽牌+费用 |
| 难度系统 | 进阶20难度等级 | 高重复可玩性 |
| 解锁系统 | 新卡牌、新遗物 | 局外成长 |
| 每日挑战 | 每日固定种子和特殊规则 | 社区互动 |
| 自定义模式 | 可自定义规则 | 增加趣味性 |
| 图鉴系统 | 卡牌、遗物、药水、怪物图鉴 | 信息收集 |

#### 竞品设计风格
- 视觉风格：手绘风格，2D平面，色彩鲜明，界面简洁
- 美术风格：偏卡通化，角色和怪物设计独特
- UI设计：信息层级清晰，操作反馈即时
- 音乐音效：氛围感强的BGM，战斗音效节奏感强
- 整体调性：硬核但不严肃，带有幽默感

#### SWOT分析

| 维度 | 分析 |
|------|------|
| **优势（Strengths）** | 1. 回合制策略天然适合PC/移动端，反应门槛低<br>2. 程序化地图 + 网格移动比卡牌路线选择更具空间策略感<br>3. 网格战棋 + 环境互动，策略深度更高<br>4. AI行为树比固定卡牌模式更动态<br>5. 物品组合制（装备+遗物+技能）比纯卡牌Build更丰富 |
| **劣势（Weaknesses）** | 1. 杀戮尖塔有先发优势和庞大用户基础<br>2. 网格战棋节奏比卡牌慢，移动端适配难度大<br>3. 开发复杂度远高于卡牌游戏<br>4. 缺乏成熟的品类认知（杀戮尖塔=卡牌Roguelike的标杆）<br>5. 美术和音乐资产需要大量投入 |
| **机会（Opportunities）** | 1. Roguelike+战棋品类尚未出现头部产品，市场空白大<br>2. 回合制策略游戏在移动端和PC端均有稳定受众<br>3. 独立游戏市场持续增长，Steam和移动平台分发渠道成熟<br>4. 可以加入杀戮尖塔没有的"空间战术"维度<br>5. 中文+全球化同时发行，收割两类市场 |
| **威胁（Threats）** | 1. 大厂可能入局Roguelike战棋赛道<br>2. 同类竞品（如《暗黑地牢2》《漫威暗夜之子》）已有一定市场<br>3. 程序化生成和AI行为树开发难度大，Bug风险高<br>4. 回合制策略游戏受众相对小众<br>5. 如果平衡性做不好，随机性会导致负面体验 |

#### 差异化策略建议
| 维度 | 差异化方向 |
|------|-----------|
| 核心玩法 | 卡牌→**网格战棋**，增加空间位置策略维度 |
| 交互方式 | 纯卡牌操作→**地图上移动+攻击+技能**的立体操作 |
| AI系统 | 固定行为模式→**行为树驱动**，敌人更智能 |
| 环境互动 | 无→**可破坏地形、陷阱、元素反应** |
| Build多样性 | 卡牌组合→**装备+遗物+技能+地形**多维组合 |
| 战斗节奏 | 快速卡牌对攻→**可深思熟虑的回合制战棋** |
