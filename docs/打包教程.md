# 打包成 exe 教程

把游戏打包成 Windows 可执行程序，发给朋友直接双击就能玩。

## 一、前置条件

- 已安装 Python 3.13 + `pygame-ce`（运行游戏正常）
- 已安装 PyInstaller（没有就装一次）：

```powershell
pip install pyinstaller
```

## 二、打包命令

在项目根目录（`d:\code\roguelike`）执行：

```powershell
python -m PyInstaller Roguelike.spec --noconfirm
```

- `Roguelike.spec` 已配置好：入口 `src/main.py`、素材 `assets/` 全部打进包、无控制台窗口
- `--noconfirm`：覆盖旧产物，不用反复确认
- 首次打包较慢（PyGame 体积大），之后重打只要一两分钟

## 三、产物与验证

打包完成后产物在：

```
dist\Roguelike\
  ├── Roguelike.exe      ← 双击运行
  ├── _internal\         ← 运行时依赖（pygame、素材等）
  └── (首次运行后生成) saves\   ← 存档目录
```

验证步骤：

1. 双击 `dist\Roguelike\Roguelike.exe` 能进入游戏主界面
2. 打一把到战斗，确认敌人动画、粒子、音效正常
3. 保存一局 → 关闭 → 重开，确认能读档（存档写在 exe 旁边的 `saves\`）

## 四、发给朋友

- 把整个 `dist\Roguelike\` 文件夹压缩成 zip 发给对方
- 对方**不需要安装 Python**，解压后双击 `Roguelike.exe` 即可
- 若对方想换存档：删除 exe 旁的 `saves\` 文件夹即重置（删档重开）

## 五、常见问题

| 现象 | 原因与解决 |
|---|---|
| 打包后图标/素材缺失 | `assets/` 没打进包。确认 `Roguelike.spec` 的 `datas=[('assets','assets')]` 存在，重新打包 |
| exe 打开闪退 | 大概率缺依赖。用 `python -m PyInstaller --console Roguelike.spec` 临时带控制台运行，看报错信息 |
| 存档丢失 | 打包版本存档在 exe 旁 `saves\`，不要从 `_internal\` 里找 |
| 换了一台电脑 | 直接把整个 `dist\Roguelike` 拷过去即可，无需重打包 |
| 字体不显示 | 确认素材目录 `assets/fonts/` 存在；打包版走 `sys._MEIPASS` 解压路径，路径不用改 |

## 六、改代码后重新打包

每次改完代码/素材，重新执行第二步的打包命令即可：

```powershell
python -m PyInstaller Roguelike.spec --noconfirm
```
