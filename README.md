# 迷城棋局（Labyrinth Chess）

基于 pygame-ce 开发的 Roguelike 回合制策略战棋游戏。

## 游戏简介

- **类型**：Roguelike + 回合制网格战棋
- **目标**：探索程序化生成的地牢，击败 Boss 通关
- **特色**：
  - BSP 算法程序化生成地图，每次布局不同
  - 回合制战斗，AP（行动点）系统
  - 行为树驱动的敌人 AI（近战/远程/Boss 三阶段）
  - 战争迷雾 + 射线检测视野
  - 装备与药水系统

## 环境准备

### 依赖

- Python 3.10+
- pygame-ce 2.5.7

### 安装

```powershell
# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境（PowerShell）
.venv\Scripts\Activate.ps1

# 安装依赖
pip install -r requirements.txt
```

## 启动游戏

```powershell
.venv\Scripts\python.exe src\main.py
```

## 操作说明

### 探索模式

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| Esc | 暂停 |
| I | 打开/关闭背包 |

### 战斗模式

| 按键 | 功能 |
|------|------|
| 1 / 2 / 3 | 切换技能（基础攻击 / 冲锋斩 / 火球术） |
| M | 切换移动模式 |
| H | 使用药水 |
| 空格 / 回车 | 结束回合 |
| 鼠标点击蓝格 | 移动到该格（消耗 1 AP） |
| 鼠标点击红格 | 用当前技能攻击 |

### 暂停菜单

| 按键 | 功能 |
|------|------|
| Esc | 继续游戏 |
| 鼠标点击 | 选择菜单项 |

## 游戏机制

### AP 系统

- 每回合 AP 重置为 5
- 移动消耗 1 AP/格，攻击消耗 2 AP，技能消耗 3 AP
- AP 归零或手动结束回合后切换到敌人回合

### Boss 三阶段

| 阶段 | HP 百分比 | 行为 |
|------|:--------:|------|
| 1 普通 | 100%~70% | 近战攻击 + 追击 |
| 2 狂暴 | 70%~40% | 2 连击 |
| 3 绝杀 | 40%~0% | AOE 震击 |

### 战利品

- Boss 必掉：长弓 + 治疗药水 ×2
- 普通战斗：50% 治疗药水 / 30% 铁剑

## 项目结构

```
src/
├── core/           # 核心系统（主循环、配置、输入）
├── states/         # 游戏状态（菜单、游戏、暂停、结算）
├── world/           # 地图生成、瓦片、迷雾
├── entities/        # 实体（玩家、敌人）
├── combat/          # 战斗系统（回合、伤害、状态）
├── ai/              # 行为树 AI
├── items/           # 物品系统
├── ui/              # UI 组件
└── utils/           # 工具（向量、随机数）
```
